# Code of conduct

PhotoChoose welcomes people who want to use, improve, test, or document the project.

## Expected behavior

- Be respectful, patient, and constructive.
- Discuss ideas and code without attacking the person behind them.
- Welcome questions and different levels of experience.
- Respect privacy. Do not publish another person's photographs, personal data, or private
  correspondence without permission.
- Accept maintainers' decisions about scope, safety, and project direction.

Harassment, threats, discrimination, sexualized conduct, deliberate disruption, and publishing
someone else's private information are not acceptable.

## Reporting a problem

Do not start a public argument about a conduct issue. Report it privately through the contact
method on the [maintainer's GitHub profile](https://github.com/cursedpc). Include relevant links or
screenshots and enough context to understand what happened.

The maintainer may edit or remove contributions, lock conversations, issue a warning, or
temporarily or permanently restrict participation. Reports will be handled as privately and
fairly as practical.

This code applies in the PhotoChoose repository and in other public spaces where someone is
representing the project.
