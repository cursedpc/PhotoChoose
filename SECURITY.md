# Security policy

## Supported versions

Security fixes are provided for the latest PhotoChoose release and the current `main` branch.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue or discussion.

Use **Report a vulnerability** in the repository's **Security** tab. Include the affected version,
operating system, reproduction steps, potential impact, and any suggested mitigation. If private
reporting is temporarily unavailable, contact the maintainer through the contact method shown on
the [cursedpc GitHub profile](https://github.com/cursedpc) without publishing technical details.

PhotoChoose is maintained as an open-source project without a guaranteed response time, but
reports will be reviewed as promptly as possible. Please allow time for a fix and release before
public disclosure.
